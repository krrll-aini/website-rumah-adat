# 🏛️ Website Informasi Rumah Adat Kuta Rekan Tatau

Website ini dibangun untuk mendokumentasikan, melestarikan, dan mengenalkan informasi seputar rumah adat, adat istiadat, serta bahasa daerah Kuta Rekan Tatau. 

## 🛠️ Teknologi yang Digunakan
* *Backend & Logic:* PHP
* *Database:* MySQL / MariaDB (File database tersedia di repository ini dengan format .sql)
* *Web Server:* Laragon Local Environment

## 📁 Fitur Utama
* Halaman Informasi Adat Istiadat & Alam Lingkungan
* Fitur Cerita Rakyat & Galeri Foto Budaya
* Halaman Admin (Dashboard) untuk Manajemen Konten Website
